# Math Worker 项目

基于小学数学 1-6 年级内容的互动式数学教学课堂。


## 内容大纲

* 首页分为十二个入口，分别为：一上、一下、二上 ... 六上、六下
* 进入某个入口之后，根据课本目录分成若干单元；单元下再拆成一节节互动主题
* 例如六上·第 5 单元「圆」→ （半径、直径与周长）、（尺规作图）
* 每个互动主题是一节课：左侧 three.js 舞台 + 右侧控制面板与数据读数


## 技术框架

* web-based（Vite + 原生 ESM，无 UI 框架）
* three.js 用于绘图（正交相机，二维平面内的数学可视化）
